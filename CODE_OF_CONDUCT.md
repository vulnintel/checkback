# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone taking part in issues, pull requests and discussions is expected
to follow it.

## Reporting

Report unacceptable behavior privately through GitHub's
[private reporting](https://github.com/vulnintel/checkback/security/advisories/new)
("Security" tab → "Report a vulnerability"; start the title with "Conduct:"), the same channel as
[SECURITY.md](SECURITY.md). For matters that do not need privacy, open an issue.

Maintainers review every report, keep the reporter's identity confidential, and act following the
Contributor Covenant's enforcement guidelines.
